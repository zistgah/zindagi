# zindagi — Geometry of Living (poster collection)

*Geometry of Living*, a sequel to *Geometry of Becoming*, by **Abhishek Choudhary** (AyeAI).
Eighteen posters, one per chapter, published as a static book on the
[**kitab**](https://github.com/zistgah/kitab) template.

- **Read:** `index.html` at the repo root (GitHub Pages serves from root). Pick a reader with
  `?reader=paginated|scroll|liquid`.
- **Each chapter** is a single poster rendered as a self-describing figure — open it, then use
  the Explain / Read-aloud / Ask-AI tools beneath it.
- **Contribute:** GitHub issues (chapter / simulation / critique / site), routed by `needs:*`
  capability labels.

Posters and chapter text are licensed **CC-BY-SA-4.0**; the kitab plumbing is GPL-3.0-or-later.
The framework is presented as an integrative research proposal, not established consensus.
